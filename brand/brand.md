# re8 brand kit

Always written lowercase: **re8**. In text, the name is simply typeset in the surrounding font — there is no wordmark, and none should ever be created or applied.

## Concept

"pixel eight" — an 8 built from sprite pixels, set in a rounded flat badge.
Flat design, single base color (teal) plus white, in the style of the Sprout Social identity system.
The middle pixel row is one shade lighter, giving the mark depth without gradients.
The mark stands alone; it is never paired with lettering as a lockup.

## Palette

| Name   | Hex       | Use |
|--------|-----------|-----|
| deep   | `#0a4f47` | hover states, text on mist |
| base   | `#0e7a6c` | primary brand color, badge fill |
| bright | `#2fbfa9` | accent row in reverse mark, highlights, links |
| light  | `#8fe3d6` | accent row in primary mark, subtle accents |
| mist   | `#e6f5f2` | tinted backgrounds, cards |
| white  | `#ffffff` | pixels on badge |

Rule: any composition uses only these six values.

## Files

- `re8-mark.svg` — badge mark, teal background (use on white/light surfaces)
- `re8-mark-reverse.svg` — white badge, teal pixels (use on teal/dark surfaces)

## Usage notes

- The mark is the entire logo. Product name appears as plain lowercase text ("re8") in the running typeface, never as drawn letterforms.
- Minimum size for the mark: 16px (favicon-safe).
- Clear space around the mark: one pixel-cell (1/5 of badge width) on all sides.
- Don't recolor outside the palette; don't add shadows, outlines or gradients.
